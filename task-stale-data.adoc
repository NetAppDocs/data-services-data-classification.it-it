= Personalizza la definizione dei dati obsoleti in NetApp Data Classification
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification identifica i dati obsoleti, così puoi trovare opportunità di risparmio e affrontare i rischi di governance. Personalizza la definizione di dati obsoleti in base alle esigenze della tua organizzazione e identifica i dati obsoleti in base all'ultimo accesso o all'ultima modifica.

I dati obsoleti possono essere definiti in base a quando sono stati _ultimamente accessi_ o _ultimamente modificati_. Puoi scegliere un periodo da sei mesi a dieci anni.

Per impostazione predefinita, i dati vengono considerati obsoleti se l'ultima modifica risale a tre anni fa.

.Definisci dati obsoleti
. In Classificazione dati, seleziona **Configurazione**.
. Nella pagina Configurazione, selezionare la scheda **Impostazioni**.
. Nella sezione Stale data definition, selezionare *Modifica*.
. Nel menu a tendina **Proprietà file**, scegli se vuoi definire i dati obsoleti in base a quando sono stati *Ultimo accesso* o *Ultima modifica*.
. Selezionare il periodo di tempo per la definizione dei dati obsoleti.
. Seleziona **Salva**.
