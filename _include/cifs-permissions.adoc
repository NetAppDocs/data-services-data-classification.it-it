+ Per assicurarti che gli orari di "ultimo accesso" dei tuoi file non vengano modificati dalle scansioni di Data Classification, configura l'utente di Active Directory con i permessi di Write Attributes in CIFS o i permessi di scrittura in NFS. Se possibile, configura l'utente di Active Directory come parte di un gruppo principale nell'organizzazione che abbia i permessi su tutti i file.
